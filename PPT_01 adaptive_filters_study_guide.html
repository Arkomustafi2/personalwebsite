⚡ What this topic is really about

Adaptive filters are FIR filters that update their own coefficients in real-time to minimize an error signal. The workhorse algorithm is LMS (Least Mean Square / Widrow-Hopf). The core theory chain is: Noise cancellation problem → Wiener filter (optimal but impractical) → Steepest descent (block-based) → LMS (sample-by-sample). Exam focus: the derivation chain, the LMS update equation, and manual numerical examples.

🎯 Noise Canceller Block Diagram — Signal Definitions

d(n) = s(n) + n(n) ← contaminated signal (primary input) x(n) ← noise reference (correlated with n(n)) y(n) = Σ w(i)·x(n−i) ← filter output = estimate of n(n) e(n) = d(n) − y(n) ← error = estimate of s(n) = ŝ(n) = s(n) + n(n) − y(n)

Two purposes of e(n) = ŝ(n)

1. Output — estimate of the desired clean signal s(n)

2. Error signal — fed back to update filter coefficients via adaptive algorithm

Key assumption

s(n) and n(n) are uncorrelated with each other. This is what allows the math to work — the cross-term E[s(n)(n(n)−y(n))] = 0.

🎯 Two Components of Adaptive Filter

Digital Filter (FIR preferred)

y(n) = Σ w(i)·x(n−i), i=0..N-1 Reasons FIR over IIR: • Simplicity • Guaranteed stability (all poles at z=0) • Linear phase

📐 SNR Maximization Proof (Slides 9–10)

This is a high-probability derivation question. Know every step.

1
Start: ŝ(n) = d(n)−y(n) = s(n)+n(n)−y(n)
2
Square it: ŝ²(n) = s²(n) + [n(n)−y(n)]² + 2s(n)[n(n)−y(n)]
3
Take expectation: E[ŝ²(n)] = E[s²(n)] + E[(n(n)−y(n))²] + 2E[s(n)(n(n)−y(n))]
4
Use uncorrelation: s(n) is uncorrelated with n(n) and y(n), so the last term = 0
5
Result: E[ŝ²(n)] = E[s²(n)] + E[(n(n)−y(n))²]
6
Conclusion: E[s²(n)] is fixed. Minimizing total output power minimizes remnant noise power → maximizes SNR
min E[ŝ²(n)] = E[s²(n)] + min E[{n(n)−y(n)}²] ↑fixed ↑minimize this → max SNR

📐 Wiener Filter Theory — MSE Surface

Define statistics

J = E[e²(n)] = MSE σ² = E[d²(n)] = power of d(n) P = E[d(n)x(n)] = cross-correlation R = E[x²(n)] = autocorrelation
e(n) = d(n) − wx(n) e²(n) = d²(n) − 2d(n)wx(n) + w²x²(n) ⟹ J = σ² − 2wP + w²R ... (5)

Optimal weight

J is quadratic in w (parabola). Minimum at w* where dJ/dw = 0: dJ/dw = −2P + 2wR = 0 ⟹ w* = R⁻¹P This is the Wiener-Hopf equation.
Why it's impractical: R and P change with data, matrix inversion is expensive, requires long data blocks (processing delay). This motivates LMS.

📐 Example 10.1 — Find w* and J_min

J = 40 − 20w + 10w² Step 1: dJ/dw = −20 + 20w = 0 Step 2: w* = 1 Step 3: J_min = 40 − 20(1) + 10(1)² = 30 Verify: from J = σ² − 2wP + w²R → 2R = 20 ⟹ R = 10 → 2P = 20 ⟹ P = 10 → w* = P/R = 10/10 = 1 ✓

📐 Steepest Descent Algorithm

Update rule: w_{n+1} = w_n − μ · (dJ/dw) If dJ/dw < 0: −μ(dJ/dw) > 0 → w increases toward w* If dJ/dw > 0: −μ(dJ/dw) < 0 → w decreases toward w* When dJ/dw = 0: w* reached.
Limitation: Still requires estimating dJ/dw from a block of data (not sample-by-sample). Solution → LMS approximates dJ/dw using a single sample.

Example 10.2 — J = 40−20w+10w², w₀=0, μ=0.04, 3 iterations

dJ/dw = −20 + 20w_n n=0: μ·dJ/dw = 0.04×(−20+0) = −0.8 → w₁ = 0 − (−0.8) = 0.8 n=1: μ·dJ/dw = 0.04×(−20+16) = −0.16 → w₂ = 0.8 − (−0.16) = 0.96 n=2: μ·dJ/dw = 0.04×(−20+19.2)= −0.032→ w₃ = 0.96−(−0.032) = 0.992 J_min ≈ 40 − 20(0.992) + 10(0.992)² = 30.0006 ≈ 30 ✓ (matches Ex.10.1)

⚙️ LMS Derivation (Single-tap)

1
Approximate J sample-by-sample: J ≈ e²(n) = [d(n) − wx(n)]²
2
Differentiate: dJ/dw = 2[d(n)−wx(n)]·(−x(n)) = −2e(n)x(n)
3
Substitute into steepest descent: w_{n+1} = w_n − μ·(−2e(n)x(n))
4
Widrow-Hopf LMS: w_{n+1} = w_n + 2μe(n)x(n)
The key insight: LMS replaces the statistical expectation E[·] with a single instantaneous sample value. This is the approximation that makes it sample-by-sample.

⚙️ Multi-tap LMS (N-tap FIR)

Filter output: y(n) = Σ w(i)·x(n−i), i = 0, 1, ..., N−1 Error: e(n) = d(n) − y(n) Weight update (for each tap i): w(i) ← w(i) + 2μ·e(n)·x(n−i), i = 0, 1, ..., N−1 Note: all N weights updated using the SAME e(n) computed at this step.

⚙️ Choosing μ (Convergence Factor)

Stability condition: 0 < μ < 1/(N · P_x) where N = number of filter taps P_x = input signal power = E[x²(n)] μ too large → diverges (unstable) μ too small → converges very slowly
For 16-bit ADC: Max amplitude A = 2¹⁵ Max power P_x < (2¹⁵)² = 2³⁰ ∴ μ = 1/(N × 2³⁰) ≈ 9.3×10⁻¹⁰ / N
In examples, μ = 0.04, 0.1, 0.5 are given directly. In the one-tap example (slides 23–25), the update uses 2μ=0.01, meaning μ=0.005.

⚙️ LMS Software Steps (Slide 22)

1
Initialize all weights w(0), w(1), ..., w(N−1) to arbitrary values (usually 0)
2
Read d(n) and x(n). Compute filter output: y(n) = Σ w(i)·x(n−i)
3
Compute error: e(n) = d(n) − y(n)
4
Update weights: w(i) = w(i) + 2μ·e(n)·x(n−i), for i = 0..N−1. Repeat from step 2.

📡 System Modeling (Slide 30)

Both the unknown system and the adaptive FIR filter receive the same input x(n). The unknown system output is d(n). The adaptive filter tries to match d(n) with y(n).

After convergence: y(n) → d(n) ∴ e(n) → 0 The AF transfer function ≈ unknown system transfer function

Example 10.4 — single-weight, μ=0.5, w₀=0

Note: 2μ = 1, so update: w ← w + e(n)x(n) y(n) = wx(n), e(n) = d(n)−y(n) n=0: y=0×0.5=0, e=1−0=1, w←0+1×0.5=0.5 n=1: y=0.5×1=0.5, e=2−0.5=1.5, w←0.5+1.5×1=2.0 n=2: y=2×(−1)=−2, e=−2−(−2)=0, w←2+0×(−1)=2.0 n=3: y=2×1=2, e=2−2=0, w←2+0×1=2.0 Converged to w=2 → unknown system is a gain-of-2 amplifier.

📡 Line Enhancement (Slide 33)

d(n) = A·cos(2πfn/f_s) + noise(n) ← corrupted sinusoid x(n) = d(n−Δ) ← delayed version by Δ samples Key principle: • Sinusoid is periodic → PREDICTABLE from its past • Wideband noise is NOT predictable from past samples • ∴ AF learns to predict the sinusoid component • y(n) = predicted sinusoid = enhanced output • e(n) = d(n) − y(n) = noise (residual)
Wait — note the output: In line enhancement, the FILTER OUTPUT y(n) is the enhanced signal, not e(n). This is opposite to noise cancellation where e(n) is the clean output.

Δ is chosen experimentally. A two-tap FIR filter is sufficient to predict one sinusoid. For K sinusoids, 2K taps are needed.
